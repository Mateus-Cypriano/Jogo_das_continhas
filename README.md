# Jogo_das_continhas
Um quizz simples de matemática básica para crianças e pais se divertirem aprendendo

Para quem quiser testar e usar ficarei muito feliz, segue link para o jogo:
https://mateus-cypriano.github.io/Jogo_das_continhas/

Reparei que meu enteado João assim como outras crianças tem dado muita atenção para telas e desenhos, deixando de lado alguns brinquedos e atividades por celulares e video game. 
E como normalmente eu programo ou jogo acho que contribuo para que ele não se interesse por essas atividades. Com isso na minha folga decidi dedicar um tempo para criar essa aplicação web e incentivar ele a 
estudar se divertindo, fiz um quiz simples em JS para ele praticar continhas básicas, com minha ajuda e da sua mãe, ja que é uma das coisas que ele mais pede, que façamos contas para ele. (ele não sabe ler ainda mas sabe fazer operações simples, e prefere matemática a português).
